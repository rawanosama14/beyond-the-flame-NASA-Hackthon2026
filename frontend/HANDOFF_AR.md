# BEYOND THE FLAME — تسليم اليوم الأول

## الهدف

المشروع هو **Frontend احترافي مبني باستخدام Next.js App Router وReact وTypeScript** لتحدّي 2026 الخاص بتلخيص أبحاث احتراق المواد في الجاذبية الصغرى.

تم تحويل فكرة النسخة المرفوعة (HTML/CSS/JavaScript) إلى هيكل Next.js منظم، مع إعادة تصميم شاملة مستوحاة من مبادئ Apple Design: حركة بسيطة وسريعة، تدرج واضح، تفاعلات ناعمة، وضع فاتح/داكن، ودعم شاشات الكمبيوتر والموبايل.

## التشغيل

بعد فك الضغط، افتح المجلد من Terminal:

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

**ملحوظة:** التحقق من تثبيت المكتبات وتشغيل Next.js لم يكن ممكنًا في بيئة إنشاء الملف بسبب عدم توفر اتصال بـ npm registry. كود TypeScript وJSX تم فحصه من ناحية الصياغة، وتم اختبار بيانات الأبحاث وترتيبها برمجيًا.

## الصفحات الجاهزة

1. **Mission Control:** الصفحة الرئيسية، خلفية لهب Vector متحركة، مؤشرات مختصرة، ثلاثة محاور السلامة، ترتيب أبحاث، وتصدير CSV.
2. **Research Explorer:** البحث والفلترة حسب تخصص الدراسة، عرض تفاصيل كل تجربة، روابط المصادر، والذهاب للمقارنة.
3. **Study Comparison:** اختيار تجربتين ومقارنة نوع الوقود والأكسجين والتهوية والأجهزة والأهداف العلمية.
4. **Safety Intelligence:** اختيار البيئة (القمر/المحطة/المريخ/العربة)، وتجربة نطاق أكسجين وسيناريو تهوية، وعرض ترتيب توضيحي للأبحاث.
5. **Flame Visual Lab:** رسم توضيحي تفاعلي مع طبقات قياس وتصوّر للشكل الكروي للهب.
6. **Research Copilot:** واجهة محادثة تفاعلية مع إجابات ثابتة توضيحية وروابط مصادر NASA ومكان جاهز لربط API لاحقًا.

## مهم جدًا للعرض أمام لجنة التحكيم

- **Day 1 Demo:** تجربة استخدام كاملة في الواجهة، لكنها ليست متصلة بقاعدة بيانات NASA PSI حتى الآن.
- أرقام ترتيب الأبحاث هي **Demo Relevance Score** وليست أرقام NASA أو تنبؤًا حقيقيًا بخطر الحريق.
- **Research Copilot** هو Guided Demo وليس ذكاءً اصطناعيًا حيًا. عند إضافة Backend حقيقي يمكن استبداله بمساعد RAG موثوق بالمراجع.
- تم تصحيح تعريف CFI-G إلى **Cool Flames Investigation with Gases**، مع توضيح أن نسبة الأكسجين 85% تخص تيار المؤكسد في التجربة وليس جو رواد الفضاء.
- رسم اللهب من تصميم الواجهة وليس تسجيل تجربة أو محاكاة حقيقية.

## الخطوة القادمة

ربط NASA PSI datasets ثم بناء طبقة لاستخراج الـ metadata والنتائج الفعلية، وبعدها بناء Research Copilot يعمل بنظام RAG مع توثيق كل إجابة بمصدر دقيق.
