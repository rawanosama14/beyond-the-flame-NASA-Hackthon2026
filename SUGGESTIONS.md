# High-value improvements not implemented

1. **Ingest the complete NASA PSI run-level datasets (very high impact / high effort).** Pull public experiment records, data files, DOI identifiers and version metadata for each investigation. The current corpus is a partial research-document set, not an experimental run database.
2. **Run a domain-expert validation round (very high impact / medium effort).** Expand the 40-question retrieval set, add blind adjudication for citation correctness and evidence faithfulness, and include explicit measurement-unit/range ground truth. Current evaluation is a small retrieval smoke benchmark.
3. **Obtain the exact fine-tuned SciBERT checkpoint and retrain/evaluate with grouped splits (high impact / medium effort).** Supplied test F1 is 0.5556 on six sentences. Validate entity labels and prevent document/run leakage before relying on neural outputs.
4. **Enable dense E5 retrieval after downloading/checksumming weights (medium-high impact / low-medium effort).** Hybrid BM25 + TF-IDF is currently the reproducible default. Dense embeddings are supported but disabled because their weights were not part of the upload.
5. **Build normalized per-investigation/per-run tables (high impact / high effort).** Separate objectives, fuel specimen geometry, oxidizer fractions, total pressure, flow, sensors, hardware and measured outputs with source-level provenance rather than only extracting mentions from papers.
6. **Collect and annotate a licensed NASA media evaluation set (medium-high impact / high effort).** Add experiment/shot/frame labels and camera calibration metadata; only then consider training a classifier or reporting CV accuracy.
7. **Add authentication and deployment observability (medium impact / medium effort).** Before public exposure, add a gateway/API key policy, request IDs, structured audit logs without secrets, storage controls and usage limits tailored to the deployment.
8. **Add query-specific Earth-application review (medium impact / medium effort).** Only report firefighter gear, fine water mist or terrestrial smoke-detector applications where a cited source explicitly supports the transfer.
9. **Add CI with immutable frontend checksum verification (medium impact / low effort).** Run backend tests, the 40-question retrieval evaluation, CV pipeline tests, OpenAPI drift checks and a read-only frontend hash comparison on every change.
